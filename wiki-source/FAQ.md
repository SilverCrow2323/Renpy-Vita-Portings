# FAQ

## Does a title in the candidate list mean it works?

No. Future tests/suggestions are only proposed candidates.

## Are videos supported?

No. The current porting constraints in the README state that videos are not supported.

## What does “failed port” mean here?

It refers to a basic Ren'Py-Vita conversion without further patches. The README separates runtime errors during a game session from titles that do not boot.

## Can I request a game?

Yes. Open an issue in the repository and include the exact title and any useful public technical details. See [Suggest a game](Game-Suggestions).

## Where can I find completed ports?

The root README links the available port repositories. Each port has its own release and installation instructions.

## Can I upload the game to help testing?

Do not upload copyrighted game files. Share a public source link, version details and reproducible technical observations instead.
