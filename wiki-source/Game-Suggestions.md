# Suggest a game

Use the GitHub Issues section to suggest a Ren'Py game for a future Vita porting test.

## Before suggesting

- Check whether the title is already in the README's candidate or failed list.
- Prefer relatively basic Ren'Py games.
- Check whether the game relies on video playback; the current documented path does not support videos.
- Do not upload the commercial game, assets, scripts or other copyrighted game files to the issue.

> [!IMPORTANT]
> **MUST KNOW!!** A suggestion is a request to evaluate compatibility. It is not a promise that a port can be built or distributed.

## Include useful details

1. Exact game title and official project/store page.
2. Ren'Py version, if known.
3. Whether the game uses video, unusual render effects or native extensions, if known.
4. Which release/build of the game the suggestion refers to.
5. Any public evidence of a previous Ren'Py Vita test.

## Open an issue

Use the repository's [Issues](https://github.com/SilverCrow2323/Renpy-Vita-Portings/issues) page and describe one title per issue so results can be tracked clearly.
